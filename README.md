# Obsidian Interactive Calendar

![](interactive-calendar-default.mp4)

>옵시디언에서 데일리 노트로 연속적인 일정을 관리할 수는 없을까?

데일리 노트를 통해 일정을 관리하는 옵시디언 사용자라면 연속적인 일정, 즉 몇 일에 거친 일정을 관리함에 있어서 명확한 한계를 경험했을 것이라 생각합니다.
- 동일한 일정을 여러개의 데일리 노트에 반복적으로 작성하고 완료 시점에는 모든 데일리 노트를 순회하며 체크한 경험.
- 하나의 노트에 기간 정보와 함께 작성했지만 기간이 시각적으로 들어나지 않아 불편했던 경험.

*옵시디언에서도 평범한 캘린더처럼 기간 일정을 시각적으로 확인하고 묶음으로 관리할 수 있는 캘린더가 있었으면 좋겠다는 생각에서 시작한 프로젝트 입니다.(데일리 노트와 연동 포함)*

## Calendar

![](interactive-calendar-calendar.mp4)

>다른 옵시디언 캘린더 플러그인들과 동일하게 기본적으로 날짜 선택시 데일리 노트가 오픈, 생성되는 기능을 제공합니다.

- 캘린더에서 날짜를 클릭시 해당 날짜의 데일리 노트가 에디터에서 열립니다.
- 데일리 노트가 없는 경우 자동으로 생성해서 열립니다.

## Task

![](interactive-calendar-task.mp4)

>캘린더 하단에 TaskView를 통해 현재 선택된 날짜의 일정들, 현재 선택된 일정을 확인하고 관리할 수 있습니다.

- 일정 관리 뷰에서 현재 데일리 노트에 추가된 일정을 체크, 해제하여 관리할 수 있습니다.
- 일정 관리 뷰에서의 일정 상태변화는 실시간으로 데일리 노트에 반영됩니다.
- 기간 일정을 체크한 경우는 해당 기간 내에 있는 모든 데일리 노트에 반영됩니다.

*만약 에디터에서 일정을 수정한 경우 새로고침 버튼을 통해 캘린더를 최신화 할 수 있습니다.*

## Period Task

![](interactive-calendar-period-task.mp4)

>플러그인의 핵심 기능, 캘린더에서 클릭 또는 드래그앤 드롭으로 데일리 노트에 간단하게 일정을 추가하고 수정할 수 있습니다. 기간 일정을 추가하는 경우 해당 기간에 속한 모든 데일리 노트에 일정이 추가됩니다.

- 클릭을 통해 특정 날짜의 일정을 추가할 수 있습니다.
- 드래그앤드롭으로 기간 일정을 추가할 수 있습니다.
- 이미 추가된 일정의 기간을 드로그앤드롭으로 쉽게 변경할 수 있습니다.
- 일정 체크와 동일하게 일정 생성(수정)은 모두 실기간으로 데일리 노트에 반영됩니다.
- 일정은 태그를 통해 구분이 됩니다.

*여러개의 데일리 노트에 반복적으로 작성할 필요 없이 한번의 드로그앤드롭을 통해 기간 일정을 추가할 수 있습니다.*

## Setting

![](interactive-calendar-settings.mp4)


>일정이 추가되는 섹션을 설정할 수 있습니다.

- 사용자는 본인의 데일리 노트 템플릿에 맞춰 일정이 추가되는 섹션을 설정할 수 있습니다.
- 플러그인에서는 각 # 로 시작하는 섹션들을 사용자에게 선택할 수 있도록 제공합니다.
- 만약 템플릿이 없는 경우 데일리 노트의 하단에 일정이 추가됩니다. 이때 섹션 헤더를 함께 추가할 수 있는 기능을 제공합니다.
